# SELOOM CONVERT MIHOMO

تطبيق Android لتحويل روابط البروتوكولات إلى إعدادات Mihomo ونقلها مباشرة إلى BoxProxy بصلاحيات Root.

## البروتوكولات المدعومة

- VLESS
- VMess
- Trojan
- WireGuard

## المتطلبات

- Android 8.0 أو أحدث.
- صلاحيات Root مفعّلة لاستخدام النقل إلى BoxProxy.
- تطبيق BoxProxy مثبت على الجهاز عند الحاجة إلى النقل.

## البناء

افتح المشروع في Android Studio أو Code on the Go، ثم نفّذ مهمة `assembleDebug` من Gradle.
